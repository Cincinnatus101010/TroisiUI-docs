# Troisi UI docs

Documentation and live demos for [`@iantroisi/ui`](https://www.npmjs.com/package/@iantroisi/ui).

**Site:** [https://cincinnatus101010.github.io/TroisiUI-docs/](https://cincinnatus101010.github.io/TroisiUI-docs/)

## Develop

Requires `@iantroisi/ui@0.2.0` or newer on npm.

```bash
bun install
bun run dev
```

## Deploy

Pushes to `main` deploy via GitHub Actions (GitHub Pages). Production build uses base path `/TroisiUI-docs/`.

```bash
GITHUB_PAGES=true bun run build
```
